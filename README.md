### 📝 Formulário Dinâmico

`PHP 8` · `MySQL` · `MVC` · `JavaScript` · `HTML5` · `Docker`

### ⚡ SQLite Export SQL

Conversor de bases SQLite para scripts compatíveis com MySQL e MariaDB, com CLI, interface Electron, interface web e relatórios automáticos de conversão.

`Node.js` · `SQLite` · `MySQL` · `MariaDB` · `Electron` · `PHP`

### 📋 Kanban Trello Clone

Aplicação Kanban responsiva com drag and drop, prioridades, etiquetas, pesquisa, atalhos, histórico para desfazer ações e persistência no navegador.

`React` · `TypeScript` · `Vite` · `Tailwind CSS` · `dnd-kit`

### 👥 Employee Management API

API REST para funcionários e departamentos, com JWT, permissões, paginação, filtros, auditoria, uploads seguros, Swagger, Docker e testes automatizados.

`Node.js` · `Express` · `TypeScript` · `MySQL` · `Zod` · `Swagger` · `Vitest`

### 🚘 AutoEscola Financeiro
